# OpenVINO / Intel Arc environment — for the quantized SUT variants.
#
# Configs with `sut.backend: openvino` load pre-quantized OpenVINO IR models
# through optimum-intel rather than through transformers:
#
#   OpenVINO/llava-v1.6-mistral-7b-hf-int8-ov     (LLaVA-INT8)
#   OpenVINO/Qwen2.5-VL-7B-Instruct-int4-ov       (Qwen-INT4)
#
# The import in src/sut/scorer.py is deferred, so torch-only users can ignore
# this file entirely — but any config with `backend: openvino` fails at
# model-load time without it.
#
# THIS IS A COMPLETE, STANDALONE ENVIRONMENT — do not install it on top of
# requirements.txt, and do not install requirements.txt on top of it. The two
# pin different majors of transformers (4.55 here, 5.3 there) and different
# torch builds; either overlay downgrades the other. Create a separate env:
#
#   conda create -n uni-ov python=3.12
#   conda activate uni-ov
#   pip install -r experiments/requirements-openvino.txt
#
# Versions are those present on the Intel Arc workstation (Python 3.12) that
# produced the Exp-23, Exp-26 and Exp-104 Phase B LLaVA results. Install the
# Intel-GPU torch build for your driver first if the default wheel does not
# expose your Arc device. See docs/ENVIRONMENT.md.
